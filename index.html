구글 스프레드시트(Apps Script Web App)에서 가상 학생 10명 명단을 읽어와 화면에 반영합니다. (시트 쓰기는 수행하지 않는 안전한 읽기 전용 모드입니다.)

※ setup.md 파일에 안내된 배포 URL을 입력해 주세요.

// 📌 구글 스프레드시트 열: 1열: 번호 | 2열: 이름 | 3열: 제출여부 | 4열: 체크시간 // 📌 Apps Script doGet 함수 (자세한 내용은 setup.md 참조): function doGet() { const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); const rows = sheet.getDataRange().getValues(); const list = []; for (let i = 1; i < rows.length; i++) { if (rows[i][0] === "" && rows[i][1] === "") continue; list.push({ no: Number(rows[i][0]) || i, name: String(rows[i][1]).trim() }); } return ContentService.createTextOutput(JSON.stringify({ status: "success", data: list })) .setMimeType(ContentService.MimeType.JSON); }
